# Invoice Payment Delay Prediction

Predict whether and by how much vendor invoices will be delayed, and understand what drives those delays.

## Approach

- Invoice status classifiers using Logistic Regression, Random Forest, Gradient Boosting, SVM and a voting ensemble
- Regression-based delay estimation
- Vendor-level analysis, block-reason modelling and block-time features
- Association rule mining with Apriori, simulation runs and an RNN experiment in Keras
